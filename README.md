# InsightFlow — End-to-End E-Commerce Data Engineering & Analytics Platform

## Project Overview

InsightFlow is an end-to-end e-commerce data engineering and analytics platform built to demonstrate the complete journey of data from raw transactional datasets to business insights.

## Objectives

- Build a reproducible data ingestion and ETL pipeline
- Clean and validate raw e-commerce data
- Design a relational PostgreSQL database
- Perform analytical SQL queries
- Conduct exploratory data analysis
- Build an interactive Streamlit dashboard
- Implement basic data quality checks
- Deploy the final application
- Document the complete project using GitHub
